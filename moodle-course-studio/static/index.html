Datos del curso

El curso se crea con el primer paso del plan. Los módulos se añaden en secciones 1..N.

Curso existente

Puedes añadir nuevas secciones a un curso existente; el plan escribirá a partir de la sección indicada.

Mapa de módulos

Cada módulo ocupa una sección del curso, en orden: lección → cuestionario.
